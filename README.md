# Анализ рынка труда России

Интерактивный дашборд сравнивает официальную статистику Росстата с оперативными объявлениями сервисов поиска работы. Карта, региональные панели и графики помогают оценить сложность поиска приемлемо оплачиваемой работы.

## Запуск

```powershell
python -m http.server 8000
```

Затем откройте `http://localhost:8000/`.

## Пересборка

```powershell
python build_rosstat_only_map.py
```

При наличии `SUPERJOB_API_KEY` сборщик добавляет вакансии SuperJob. Секретный ключ не записывается в файлы проекта.

## Источники и ограничения

Периоды, ссылки, методика и ограничения каждого показателя описаны внутри дашборда. Онлайн-выборка не считается полной переписью рынка.
